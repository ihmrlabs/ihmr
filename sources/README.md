# Sources

Primary material - government reports, survey data, programme documentation, published research
- converted to Markdown so you can read what we read.

We do this so that any claim can be traced to the thing it came from, quoted precisely, and
checked without hunting down a PDF.

Each file records where it came from, when we retrieved it, who published it, and under what
licence.

**Material we are not permitted to redistribute is referenced rather than copied.** Third-party
material keeps its own licence and copyright, recorded per file - this repository's CC BY 4.0
licence does not extend to it.
