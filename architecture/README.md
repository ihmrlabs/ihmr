# Architecture

How the health maintenance rail might be built, and how the project's own infrastructure works.

Everything here is proposal rather than description. **Nothing in this folder describes a system
that exists and runs.** If we ever build something real, we will be clear about which is which.

If you build systems for a living, this is where we would most like you to look for the flaw we
have not seen.

Usually `proposal` or `specification`.
