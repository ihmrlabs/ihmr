# Experiments

Things we tested, and what actually happened - run in
[`ihmr-engine`](https://github.com/ihmrlabs/ihmr-engine).

Each experiment records its question, method, inputs, rules, random seed, the engine commit it
ran at, its results, and what it changed about our thinking. That includes the times the answer
was "nothing," or "the idea did not survive." Those get written up too.

**If a number appears anywhere in this repository and cannot be traced back to a run you could
reproduce, it should not be there.** Please hold us to that.
