# Decisions

Positions we have adopted — for now.

Each one records the decision, the evidence behind it, what else we considered, why we chose
this, the date, and anything it replaces.

**Decisions are not permanent.** When one changes, we mark the old one `superseded` and keep it
exactly as it was. We do not delete it and we do not quietly rewrite it — the reasoning stays
where you can find it, because how we got somewhere matters as much as where we ended up.

If you think one of these is wrong, please say so.

`decision` or `superseded`.
