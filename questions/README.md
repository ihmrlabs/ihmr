# Open Questions

The things we do not know.

This is not a backlog or a confession - it is the invitation, and probably the best place to
start if you are wondering where you could help. If you can answer one of these, or show us it
is the wrong question entirely, that is the most valuable thing anyone can give this project.

Each question says why it matters, what would count as an answer, and what we have already
ruled out so you are not retracing our steps.

Questions get answered by evidence, not by argument. If you have the evidence, we would love to
hear it.
