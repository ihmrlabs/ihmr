# Updates

A dated log of what changed and what we learned. One file per update.

Real changes only: research published, a position adopted, an assumption abandoned, an
experiment run, a correction someone sent us that turned out to be right.

**We log changes of mind as prominently as progress.** A project that only records forward
motion is not really recording anything.

This is also the honest place to see how fast - or slowly - the work is actually moving.
