# RFCs

**Request for Comments** - proposals for how some part of IHMR might work.

A note on the name, because it trips people up: at the IETF an RFC is a *finished* standard.
Here it means exactly what it says - **a proposal open for comment**, not a decision. If we
adopt one, it graduates into a `decision`.

An RFC should say what it proposes, what problem it solves, what else we considered, what it
would cost, how it could fail, and what would show it to be wrong.

Comments are the point. Please leave some.

`proposal` → `specification`, or `superseded`.
